# Checkpoint IX - Cálculo de IMC com ASP.NET MVC

## Descrição

Este projeto foi desenvolvido utilizando ASP.NET MVC.

A aplicação recebe o peso e a altura do usuário através de um formulário e realiza o cálculo do IMC no Controller utilizando processamento Server Side.

## Tecnologias utilizadas

- ASP.NET MVC
- C#
- HTML
- CSS

## Fórmula utilizada

IMC = Peso / (Altura × Altura)
